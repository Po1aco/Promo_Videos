# Promo_Videos

Promo video toolkit: Vite + React + Tailwind with motion, 3D, video-render and audio libraries.

**Included:** three, react-three-fiber, anime.js, motion, lottie-web, gsap, tone, wavesurfer.js,
motion-canvas, revideo, hyperframes, and a shadcn/ui config with the magicui, react-bits and
motion-primitives registries.
**Python (optional):** manim, faster-whisper (`requirements.txt`).
**Not included:** remotion (paid at 4+ staff), elevenlabs (paid account), magic-mcp (needs API key).
ffmpeg must be installed on the machine.

```
npm install
npm run dev
```
Add UI kit parts with e.g. `npx shadcn add @magicui/marquee`.
